The CoreCollective Virtualization Working Group supports a growing
self-sustaining Arm open source ecosystem for Virtualization technologies.

The working group is divided in three subgroups:

* Xen
* QEMU/KVM
* VirtIO 

## Joining

## Exploration Areas

### Xen hypervisor

Implementing missing architectural features in the Xen hypervisor for Arm, targeting Pointer Authentication, GICv5 support, and new atomic operations, alongside hardening real-time capabilities for certification efforts.

### QEMU/KVM

Exercising KVM APIs and implementing logic for new architectural features using QEMU as the foundational Virtual Machine Monitor (VMM). This includes leveraging QEMU's dynamic JIT (TCG) for ISA virtualization and block layer capable of supporting complex copy-on-write storage chains.

### VirtIO

Upstreaming virtio-msg, a new message-based transport protocol for VirtIO. This fills the gap for environments where existing trap-and-emulate transports (like PCI or MMIO) are not natural abstractions, such as Asymmetric Multiprocessing (AMP) systems, secure partitions, firmware co-processors, or software-only VM-to-VM endpoints.

Active VirtIO projects are ongoing, but there is always room to <a href="/join/" target="_blank">join the collaboration</a>!
