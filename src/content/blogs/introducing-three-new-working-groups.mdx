CoreCollective brings the Arm ecosystem together to identify shared challenges and solve them collaboratively in open source. Working groups turn those discussions into action. This month, we’re launching three new groups addressing key needs across the Arm software stack: Architecture Baseline for Distributions, Cloud Native Parity & Performance, and UEFI Architecture.

Our working groups are open forums, and anyone is welcome to join. Here’s what each new group will focus on and how to take part in its first call.

## Architecture Baseline for Distributions

The Arm architecture continues to evolve, with each new version bringing features that improve performance, strengthen security, and enable new kinds of compute.
Software developers naturally want to take advantage of the latest capabilities, but doing so comes with a tradeoff as older silicon doesn't support the newer features.

The [Architecture Baseline for Distributions working group](/working-groups/arch_baseline/) brings Arm Linux distributions and developers together to coordinate common baseline features beyond the original Armv8.0 architecture. The goal is to enable full performance while supporting the widest possible range of hardware.

**First meeting: Tuesday, 1 December 2026, at 5:00pm GMT.** Visit the [working group page](/working-groups/arch_baseline/) for call details.

## Cloud Native Parity & Performance

Arm support is mature across much of the cloud native ecosystem, and hyperscalers offer Arm instances that customers are using without fuss.
At the same time, Arm in cloud native is a relative newcomer and there is still substantial scope to optimize workloads and completely unlock the performance and capabilities.

The [Cloud Native Parity & Performance working group](/working-groups/cloud_native/) will build on that strong Arm64 baseline to achieve full platform parity with established architectures for cloud native workloads. The group will collaborate on native CI pipelines, establish performance regression testing, and work with maintainers to make Arm64 a tier-1 architecture within their projects.

**First meeting: Thursday, 3 December 2026, at 3:00pm GMT.** Visit the [working group page](/working-groups/cloud_native/) for call details.

## UEFI Architecture

The Unified Extensible Firmware Interface (UEFI) enables operating systems to boot on Arm platforms and provides interfaces for managing system security and boot policy. It is a foundational building block for a standard, dependable Arm platform.

The [UEFI Architecture working group](/working-groups/uefi_arch/) will coordinate discussions on UEFI implementation, architecture, and usage. It will complement specification work in the [UEFI Forum](https://uefi.org/) by focusing on implementation and encouraging common infrastructure.

**First meeting: Tuesday, 8 December 2026, at 3:00pm GMT.** Visit the [working group page](/working-groups/uefi_arch/) for call details.
